# ADR-0004：真实 Spring 对照基线钉在 6.2.x

- **状态**：已接受
- **日期**：2026-10-27
- **决策者**：LandFairy

## 背景

本书每章都有一节 **"🔍 真实 Spring 里它在哪"**，给出全限定类名、方法签名，
必要时给出行号。这要求钉死一个对照基线——否则行号会随版本漂移，全部失效。

候选：

- **6.2.x**：成熟稳定，与 Spring Boot 3.x 生态完全对齐，JDK 17 起步
- **7.0.10**（当前最新，2026-10-22 发布；7.0.0 发布于 2025-11-13）

## 决策

对照基线为 **spring-framework 6.2.x**。

每个 milestone release 时，在 release notes 里记录当时核对所用的 commit hash，
以便将来可以精确复现。

第 35 章（收官）会额外包含一节 **"6.x → 7.0 变了什么"**，避免读者的知识在最新版本上
立刻过时。

## 后果

### 正面

- **与读者的实际环境对齐**。绝大多数在用 Spring 的人跑的是 Boot 3.x → Spring 6.x。
  对照 6.2.x 意味着读者能在自己的项目里直接验证我们讲的东西。
- **资料丰富**。6.x 有大量的既有分析文章、Stack Overflow 问答、issue 讨论，
  读者遇到疑问时搜得到答案。7.0 周边的中文资料目前还很稀薄。
- **JDK 基线一致**。6.2.x 要求 JDK 17，本书的 `maven.compiler.release` 也是 17。
  读者不会遇到"书里能跑我这里不能跑"的版本错配。

### 负面

- **不是最新版本**。7.0 已发布近一年，某些地方（尤其是 AOT / native image 相关）有变化。
  缓解：第 35 章专门讲差异；且本书聚焦的 IoC/AOP 核心机制在 6→7 之间没有结构性变化。

## 备选方案

**钉 7.0.10**
最新，但与读者实际环境脱节，且可搜到的辅助资料少。**已否决。**

**不钉版本，只说"最新版"**
行号对照必然失效，且不同读者看到的东西不一致。**已否决。**
