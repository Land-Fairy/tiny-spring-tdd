# Triage Labels

| Role | Label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，AFK agent 可直接执行 |
| `ready-for-human` | `ready-for-human` | 需要人类完成 |
| `wontfix` | `wontfix` | 不会处理 |

项目自有标签：

| Label | 用途 |
|---|---|
| `spec` | 规格说明（`/to-spec` 产出） |
| `chapter` | 章级施工 ticket |
| `infra` | 脚手架 / 工具链 / CI |
| `docs` | 纯文档 |
