## 四、读者会在哪一段放弃

§3.6「为什么不做 jar」。这一节本该是「诚实交代边界」的样板——它明说了「本章只支持目录」，但紧接着许诺「明确抛出消息说明不支持 jar」，读者真去 `jar` 里跑一次，只会看到 `No candidate components found`，然后把这一整节的解释当成作者没验证过的推托。

## 五、总判词

本章是全书**技术密度最高**的一章：手写 `.class` 解析器（不依赖 ASM）拿到类名、注解、方法引用，再用元注解递归判断派生注解、用类型指针判断循环。289 行吃掉上游 593 行（`SimpleMetadataReader`），而且「为什么反射不行」那一节用「初始化计数从 0 到 1」实测钉住，是全书最好的一条实验设计。缺陷性质全部是「叙述没有跟上代码」——三处类名、两处静默行为、一处错误数字。
