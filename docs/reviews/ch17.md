## 读者会在哪放弃

读到 `findClassFiles` 去 IDE 里找，找不到；再看到 `this.resourceLoader` 编译不过。**两处虚构引用连着出现**，新人会先怀疑自己。

## 总判词

「我手写一个扫描器」这条主线是对的，`SimpleMetadataReader` 用 ASM 读 class 也是全书少见的硬活。但**方法名与字段名是照着记忆写的**，导致可复制性为零。修完 A1/A2/D1 后可跟。
