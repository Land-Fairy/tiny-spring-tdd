## 二、P0 清单

### A 类 · 代码缺陷（可复现）

| # | 位置 | 事实（E1，我实测） |
|---|---|---|
| A1 | `step-10-…/util/PropertyPlaceholderHelper.java:103` | 替换完成后 `start = result.indexOf(prefix, start)`——**从插入点重新扫**，而循环守卫用的 `visited` 已在 `:90` 的 `finally` 里清空。于是属性值里再含同名占位符时原地打转：`a=${a}` 解析 `"${a}"` 永不返回（我编译该类并 `timeout 6 java …` → **退出码 124**）。上游同处是 `indexOf(prefix, start + propVal.length())`，跳过刚插入的值 |
| A1′ | 同文件 `:79` | 那个 `"Circular placeholder reference"` 守卫只能拦住**名字里套名字**的循环（`${${a}}`），拦不住**值里套值**的循环。本章讲「循环引用会被发现」时读者会以为两种都拦，实际后一种是挂住 |

**修法**：`start = result.indexOf(this.placeholderPrefix, start + propVal.length());`（一行）。改完要补一条测试：`a=${b}, b=${a}` 应当抛 `IllegalArgumentException` 而**不是**挂住——但按现有 `visited` 语义它仍会挂，所以正确修法是**两个动作**：①跳过已插入的值；②把 `visited` 的清理挪到整个替换完成之后（或改成按「名字 + 展开深度」计数，超过阈值报循环）。**我没有改**——这会改变运行时行为，需要你拍板走 issue。

## 三、P1

1. `docs/chapters/10-bean-factory-post-processor.md:339` 的片段编译不过（E1 实测签名）：`new MapPropertySource("test", Map.of("db.url", "jdbc:hsqldb:mem:test"))` —— 构造器是 `MapPropertySource(String, Map<String, Object>)`（`core/env/MapPropertySource.java:24`），而 `Map.of(k, v)` 推断成 `Map<String, String>`。修法：`Map.<String, Object>of(...)` 或先声明成 `Map<String, Object>` 变量。
2. `docs/chapters/10-bean-factory-post-processor.md:18` 把 `<bean class="org.springframework.samples.ch10.JdbcConfig">` 说成「第 08 章留下的现场」，但 `JdbcConfig` 只存在于 `step-10-…/src/test/java/…/samples/ch10/JdbcConfig.java`，第 08 章模块里没有这个类。照抄到 08 模块会 `ClassNotFoundException`。
3. `AbstractApplicationContext.java:395` 的 `getEnvironment()` 返回具体类 `StandardEnvironment`（字段 `:50` 亦定死该类），而接口 `ConfigurableApplicationContext.java:65` 声明的是 `Environment`——具体类进了公开签名。
4. 「命令行的 `-D` 参数进 systemProperties」这句话在本书不成立（没有 systemProperties 来源），建议统一改成「本书的环境链只有一条 map」。

## 四、读者会在哪一段放弃

占位符那一节。这是全书第一次讲「值里还能套占位符」——很有价值，但紧接着的「循环引用会被发现」会让人去试 `a=${a}`，然后 IDE 卡死/进程不返回。教学代码里出现**挂住**而不是**报错**，比报错严重得多：报错教人改，挂住教人怀疑环境。

## 五、总判词

本章的设计是好的：`Environment` 把「属性从哪来」（`PropertySources` 链）与「值怎么解释」（`PropertyResolver`）切开，`MutablePropertySources` 用一个 `List` 保序，BFPP 让配置在「造 Bean 之前」被改写一次——这三件事凑齐了 Spring 外部化配置的全貌。硬伤是一个**一行的下标计算错误**（A1），它把「优雅的递归下降」变成了死循环。这正是 AI 评审要抓的东西：结构全对，一行下标错。
